# FindBack — Community Lost & Found

FindBack is a mobile-first community app prototype that helps people report, discover and safely return lost belongings.

## Problem
Lost items are often reported across noisy social media groups, making them difficult to search and match. People also need safer ways to communicate before arranging a handover.

## Target users
Students, commuters, families, schools, community groups and local residents.

## Core features
- Search and category filters
- Lost/found item reports
- Area-based discovery
- In-app messaging concept
- Community profile and trust/safety guidance
- Local browser storage for demo reports

## Run locally
Open `findback_app.html` in a modern web browser. No server or external API is required.
